# ZZP 公开项目架构与维护边界

这是一组独立的小产品和资源发布工具。入口提供发现路径，仓库承担各自生命周期，不建立统一平台或公共运行服务。

## 职责

| 部分 | 核心职责 | 数据与发布 |
| --- | --- | --- |
| 项目入口 | 找到工具、资源和接入说明 | 手工维护公开链接，静态页面 |
| 基金再平衡 | 固定组合的金额计算与执行清单 | 当前页面内计算，不保存持仓；独立离线缓存 |
| Anki 模板与制卡 | 原生卡片、浏览器编辑与文件交换 | 浏览器草稿；官方 Anki 后端生成安装包 |
| 图片资源库 | 分类、搜索、预览、收藏与稳定原图地址 | 资源登记与生成目录；本机收藏 |
| RouterOS Adlist | 把 anti-AD 转成 hosts | 校验上游后生成公开列表 |
| sing-box 广告过滤 | 转换 AdGuard DNS Filter | 固定转换器，记录精确上游提交 |
| sing-box 例外分流 | 少量代理 / 直连覆盖 | 人工 JSON、自动 SRS；不承载完整配置 |
| Zashboard 界面设置 | 可公开分享的外观与偏好 | 严格验证；设备映射留在私有范围 |
| GitHub 个人资料 | 身份与项目入口 | README 链接，不复制项目目录 |

保留这些仓库边界：用途、更新频率、许可与失败影响各不相同。规则更新不应重建 Anki，资源更新不应触碰配置；广告规则的 GPL 来源也不适合并入所有代码的共同包。私有内容具有独立的访问和恢复边界，不从公开项目枚举或同步。

## 页面与技术

入口使用温和的目录式布局；再平衡以输入、诊断、方案和执行为主线；图库以资源用途导航和图片为中心；制卡工具以笔记列表、编辑与预览为中心。共同点只保留易识别的身份、项目返回入口和基本可访问性，不强求相同配色、卡片和导航。

各项目分别维护外观，内部可以共享自己的语义变量与基础样式，不建立跨项目的共同主题发布或 CSS CDN。共享代码只在同一业务内有收益时提取，例如图库查询模块、Anki 类型规格和计算核心。

网页继续使用浏览器原生 HTML、CSS、JavaScript。现有规模不需要路由框架、打包器或服务端；静态页面可直接预览。规则与恢复命令采用 Python 标准库，编译和原生卡片功能交给官方 sing-box 与 Anki。已经评估 Rust / WebAssembly：当前瓶颈主要是信息组织、文件校验和维护流程，新增编译链不会改善主要路径，故不引入；若以后出现独立、可测量的数据处理瓶颈，再单独评估。

## 稳定性与公开边界

- 应用分别使用自己的 Pages 项目路径，不迁到 `zzp.moe` 子路径。名称或地址变化时同步更新导航、引用、安装身份与部署；原图和 raw 规则地址按各自用途保持稳定，浏览器草稿与收藏仍由所属项目维护。
- Anki 的类型、字段、模板、示例 GUID 与交换格式继续稳定；内部网页文件可以重新组织，不保留无消费者的兼容副本。
- 各 Service Worker 只处理自身路径和缓存前缀。入口没有根路径 Service Worker；再平衡按完整版本缓存，图库对必需文件校验内容并限制可选预览缓存。
- 公开配置拒绝凭据、节点链接、私人地址和设备映射；私有恢复产物不进入公开仓库、页面或日志。前端隐藏入口与公开目录中的内容可被访问，是呈现选择，不是权限隔离。
- 网页部署采用检查后的文件白名单，不把测试数据、开发依赖和本地导出目录一起发布。

## 验证与恢复

每个仓库的 README 是使用入口，维护文档和工作流是本项目的实际流程。没有统一测试命令要求：计算验证整数守恒，Anki 验证原生导入和排程，图库验证登记 / 缓存 / 浏览交互，规则验证源数据与官方转换。网页覆盖 Chromium / WebKit、桌面 / 手机 / 平板和浅深色；自动化不能替代真机安装与原生客户端检查。

Pages 仅在检查成功后发布，失败保留原版本；公开生成规则仅在转换成功后提交；本地恢复使用独立输出和原子替换。Git 保存历史，通常用撤销提交和重新发布恢复，不在当前目录保存历史实现，也不重写公共历史。

## 参考与许可

研究了 [GitHub Primer 的焦点管理](https://primer.style/accessibility/design-guidance/focus-management/)、[实际 focus-trap 源码](https://github.com/primer/behaviors/blob/main/src/focus-trap.ts)和 [W3C 原生 dialog 技术](https://www.w3.org/WAI/WCAG22/Techniques/html/H102)，用于确认对话框焦点进入、关闭与恢复路径。实现使用浏览器原生 dialog 与项目自己的少量控制代码，没有复制 Primer 组件或品牌资产。

[官方 sing-box 转换器](https://sing-box.sagernet.org/configuration/rule-set/adguard/)与官方 Anki 后端继续承担格式语义，没有另写替代解析器。自有项目保留原许可，广告规则保持 GPL-3.0 与对应上游提交；图片资源逐项保留来源和原权利人的许可，没有把整个资源库重新授予统一许可。来源不明的旧图片仍需以后逐项核实，现有记录不代表已经取得额外授权。
