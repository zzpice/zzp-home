## 性能记录

当前发布产物 36 个文件，800,144 字节（约 0.8 MB，未压缩，含项目预览与来源许可）。首页正文内嵌正式配置，没有额外导航 JSON 请求。首屏浏览测得 HTML 加 5 个资源：CSS、app.js、model.js、站点 SVG、共用图标图集；编辑器延迟加载。

图集 323,789 字节，供当前全部网站复用。HTML、两段浏览 JS、CSS 和图集的本地 gzip 估算合计约 350 KB。该值是本机压缩估算，不是 GitHub Pages 线上传输测速；真实网络、CDN 缓存和浏览器表现仍取决于访问环境。循环本地访问的绘制时间不能代表慢网体验。

Worker 在空闲时建立完整离线缓存，因此首访后台会再取得项目页、编辑器、预览和许可等资源；与首屏请求范围不同。版本路径资源优先复用 HTTP 缓存并校验，失败时跳过该缓存重取一次；完整版本安装后普通重访不重新下载全量图标和数据。
